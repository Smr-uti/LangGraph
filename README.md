# 🚀 LangGraph Programs & Workflows

Welcome to my repository! This repo contains a collection of LangGraph programs, practice scripts, and advanced agent workflows built using Python and LangChain.

## 📂 What's Inside?
Here you will find various implementations of LangGraph concepts:
- **Basic Graphs:** Setting up nodes, edges, and state.
- **Cyclical Workflows:** Implementing loops for agentic decision-making.
- **Multi-Agent Systems:** Collaborative agent workflows.
- **Human-in-the-Loop:** Adding approval steps and checkpoints.
- **Memory & Persistence:** Managing state across conversation turns.

## 🛠️ Tech Stack
- **Python**
- **LangChain & LangGraph**
- **LLMs (OpenAI / Anthropic / Local models)**
